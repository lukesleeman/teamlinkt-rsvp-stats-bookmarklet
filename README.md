# TeamLinkt RSVP Stats Bookmarklet

A bookmarklet that shows who RSVPed to past [TeamLinkt](https://app.teamlinkt.com/) events, broken down by kind of event and by member.

## Installation

<!-- BOOKMARKLET_START -->
1. Copy the bookmarklet code from below
2. Create a new bookmark in your browser
3. Set the name to "TeamLinkt RSVP Stats"
4. Paste the code as the URL/location
5. Save the bookmark
<!-- BOOKMARKLET_END -->

## Usage

1. Log in to TeamLinkt and pick your team
2. Click the bookmarklet in your bookmarks bar

## Development

```bash
npm install
npm run build
npm test
```

- `npm run build` - Build the bookmarklet and update this README
- `npm run dev` - Build in development mode with watch
- `npm test` - Build, then run the tests
